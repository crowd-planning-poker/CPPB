# Introduction

The UI log traces were captured for 1,449 crowd workers, resulting in over five million UI interaction events. Those records transformed into CPP actions which comprise the Crowd Planning Poker Behaviour (CPPB) dataset.  The included UI events were selected since they can provide information about targeted crowd actions. This repot consists of the dataset in three formats as follows.

## Files

- `cpp_trace_log_db.sqlite3`: the dataset in an SQL database.

- `trace_log_xes_v2.xes`: the dataset in an eXtensible Event Stream.

- `trace_log_csv_v2.csv`: the dataset in an CSV file.
